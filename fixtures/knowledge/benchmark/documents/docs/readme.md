# Workbench

The workbench runtime manages workspaces, agents, and projects. It provides
a CLI and a local-first dashboard for declarative, reproducible agent
environments.

## Getting started

- Read `docs/architecture.md` for the design overview.
- Read `docs/cli.md` for command line usage.
- Read `docs/contributing.md` before submitting changes.

## Repository layout

- `src/` contains runtime code.
- `tests/` contains the test suite.
- `fixtures/` contains acceptance fixtures.
